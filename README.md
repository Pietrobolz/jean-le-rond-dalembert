# I Lumi in rete — Jean le Rond d’Alembert

Percorso didattico interattivo sul pensiero, le opere e l’influenza di d’Alembert, realizzato per il progetto scolastico **I Lumi in rete**.

## Avvio

Apri `index.html` in un browser. Il sito è statico e non richiede installazioni.

## Dialogo simulato

Il chatbot usa risposte predefinite, curate per il ripasso e accompagnate da fonti. Non è un modello IA e non genera citazioni o risposte libere. L’illustrazione dell’avatar è originale, non un ritratto storico.
