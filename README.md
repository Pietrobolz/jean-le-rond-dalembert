# I Lumi in rete — Jean le Rond d’Alembert

Percorso didattico interattivo sul pensiero, le opere e l’influenza di d’Alembert, realizzato per il progetto scolastico **I Lumi in rete**.

## Avvio

Apri `index.html` in un browser. Il sito è statico e non richiede installazioni.

## Dialogo simulato

Il chatbot offre due modalità:

- **Risposte verificate**: risposte predefinite per il ripasso, accompagnate da fonti.
- **IA locale facoltativa**: attivabile con il pulsante nella chat. Usa WebLLM e il modello `Qwen2.5-0.5B-Instruct-q4f16_1-MLC` direttamente nel browser, senza account, API key o costi di inferenza. Il primo avvio scarica il modello (centinaia di MB) e richiede un browser con WebGPU; il traffico dati, l’elettricità e le risorse del dispositivo restano a carico dell’utente. Se il modello non è supportato o non si carica, la modalità con risposte verificate continua a funzionare.

Le risposte generate sono una simulazione didattica, possono contenere errori e non sono citazioni autentiche: confrontale con le fonti indicate. Il modello e la libreria vengono scaricati da servizi esterni; non sono richieste chiavi segrete nel sito. L’illustrazione dell’avatar è originale, non un ritratto storico.
